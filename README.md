# Homework app

A small website where an administrator sets homework (questions generated by AI)
and students answer it with AI hints. AI calls go through the **Claude Agent SDK**,
which runs your local Claude Code login — so on your own machine it uses your
Claude Code subscription rather than API billing.

## Run

```
npm install
npm start
```

Open http://localhost:3000. On first start an admin account is created and printed
in the terminal (default `admin` / `admin123` — change it with the env vars below).

## How it works

- **Admin** (`/admin`): generate questions with AI (subject, topic, level, count),
  edit them, assign to all or selected students, add/remove students, and view
  each student's answers and the hints they used.
- **Student** (`/student`): see assigned homework, save progress, ask for up to
  3 AI hints per question (hints never reveal the answer), submit once.
- Data is stored in `data/db.json`. Passwords are hashed with scrypt.
- AI code lives in `ai.js`; everything else is `server.js` + `public/`.

## Configuration (environment variables)

| Variable | Default | Purpose |
|---|---|---|
| `PORT` | `3000` | HTTP port |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | `admin` / `admin123` | First-run admin account |
| `SESSION_SECRET` | random each start | Set this so logins survive a restart |
| `AI_MODEL` | Claude Code default | e.g. `sonnet` for faster hints, `opus` for best quality |
| `ANTHROPIC_API_KEY` | unset | If set, the SDK bills the API instead of your Claude Code login |

## Notes

- The SDK needs the `claude` CLI logged in on the machine running the server.
  Subscription auth is meant for your own use; if you host this for others as a
  service, switch to an API key.
- Each AI request spawns a short `claude` process (~5–15 s). Fine for a class;
  not designed for hundreds of concurrent users.
- For real deployment: put it behind HTTPS, set `SESSION_SECRET`, change the
  admin password, and back up `data/db.json`.
