# Homework app

A small website where an administrator sets homework (questions generated by AI)
and students answer it with AI hints.

It runs in two modes, picked automatically:

| | AI backend | Storage | Cost |
|---|---|---|---|
| **Locally** (no `ANTHROPIC_API_KEY`) | Claude Agent SDK → your **Claude Code login** | `data/db.json` | Your Claude subscription |
| **Vercel** (`ANTHROPIC_API_KEY` set) | Claude API (`@anthropic-ai/sdk`) | Postgres (Neon) | Pay-per-use API key |

## Run locally

```
npm install
npm start
```

Open http://localhost:3000. On first start an admin account is created and printed
in the terminal (default `admin` / `admin123`).

## Deploy to Vercel

1. **Import the repo** at vercel.com → Add New Project → pick `LogansHomework`.
   Leave the framework as "Other"; `vercel.json` configures the rest.
2. **Add a database:** in the project, go to **Storage → Create Database → Neon (Postgres)**
   and connect it. This sets `DATABASE_URL` automatically. Tables are created on first request.
3. **Set environment variables** (Settings → Environment Variables):

   | Variable | Value |
   |---|---|
   | `ANTHROPIC_API_KEY` | Your API key from console.anthropic.com |
   | `SESSION_SECRET` | Any long random string (e.g. `openssl rand -hex 32`) |
   | `ADMIN_PASSWORD` | The admin password you want (only used when the admin is first created) |
   | `AI_MODEL` | Optional. Defaults to `claude-opus-5`; `claude-sonnet-5` is cheaper/faster |

4. **Deploy.** Log in at `https://<your-project>.vercel.app` as `admin`.

Each AI call is a single API request (roughly 3–10 s), so it fits inside the
60‑second function limit configured in `vercel.json`.

## How it works

- **Admin** (`/admin`): generate questions with AI (subject, topic, level, count),
  edit them, assign to all or selected students, add/remove students, and view
  each student's answers and the hints they used.
- **Student** (`/student`): see assigned homework, save progress, ask for up to
  3 AI hints per question (hints never reveal the answer), submit once.
- Model answers are stored server-side only and never sent to student pages.
- Logins use signed, HTTP-only cookies (no server-side session store), so they
  work on serverless hosts. Passwords are hashed with scrypt.

Files: `server.js` (routes) · `ai.js` (both AI backends) · `store.js` (JSON file or
Postgres) · `auth.js` (cookie sessions) · `public/` (pages) · `api/index.js` (Vercel entry).

## All environment variables

See `.env.example`. Summary:

| Variable | Default | Purpose |
|---|---|---|
| `ANTHROPIC_API_KEY` | unset | If set, use the Claude API instead of your Claude Code login |
| `AI_BACKEND` | auto | Force `api` or `agent-sdk` regardless of the key |
| `AI_MODEL` | `claude-opus-5` (API) / Claude Code default (Agent SDK) | Model override |
| `DATABASE_URL` / `POSTGRES_URL` | unset | Postgres connection string; unset = JSON file |
| `SESSION_SECRET` | random each start | Set it so logins survive restarts / across serverless instances |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | `admin` / `admin123` | First-run admin account |
| `PORT` | `3000` | Local HTTP port |

## Notes

- The Agent SDK path needs the `claude` CLI logged in on the machine running the
  server; subscription auth is for your own use, which is why the hosted mode
  uses an API key instead. The Agent SDK is an optional dependency and is skipped
  on Vercel (`npm install --omit=optional`).
- The Postgres backend stores each record as a JSON document in three tables
  (`users`, `homework`, `submissions`) — simple, and easy to inspect in Neon's console.
